# AWS Cloud Portfolio

A responsive cloud and software engineering portfolio hosted using Amazon S3
and distributed through Amazon CloudFront.

## Architecture

Visitor → CloudFront → Private S3 Bucket

## Technologies

- Amazon S3
- Amazon CloudFront
- Origin Access Control
- HTML
- CSS
- Git and GitHub

## Features

- Responsive layout
- Cloud-themed visual design
- SVG portrait frame
- Accessible reduced-motion support
- Project and skills sections
